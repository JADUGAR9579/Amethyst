# Complex Hello World

This is a complex Python hello world program.

## File
`complex_hello_world.py`

## Features
- Multiple greeting styles: casual, formal, poetic, cyberpunk
- Dataclass-based greeting model
- Retry logic for simulated flaky I/O
- Decorators for logging and profiling
- Async broadcast mode
- CLI with multiple options

## Usage
```bash
python3 complex_hello_world.py
python3 complex_hello_world.py --recipient "Amethyst" --style cyberpunk --emphasis 2
python3 complex_hello_world.py --broadcast --log-level DEBUG
```
